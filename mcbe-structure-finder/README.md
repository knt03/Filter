# 統合版 構造物座標帳

Minecraft 統合版（Bedrock Edition）のシード値を入れると、スポーン地点（原点）の周り ±10000 ブロックにある構造物の座標を全部書き出すツールです。非公式ツールです。

- ブラウザ版: `web/`（`index.html` を開くだけ。計算はすべて端末の中で行い、どこにも送信しません）
- コマンドライン版: `build/mcbe-structures`（CSV を出力）

## 出せる構造物

| 種類 | 確かさ |
|---|---|
| 村 | 実機・Chunkbase の座標と一致を確認 |
| 砂漠のピラミッド / ジャングルの寺院 / ウィッチの小屋 / イグルー | Chunkbase の座標と一致を確認 |
| 試練の間 | Chunkbase の座標と一致を確認 |
| ネザー要塞 / 砦の遺跡（形も出る） | 統合版のサーバー（BDS）の `/locate` 85 件と、実機のワールドデータ 5 つの要塞・砦の遺跡と一致を確認 |
| スライムチャンク | 確定（シード値によらない。複数の解析ツールとテスト用の座標で一致） |
| エンドシティ / エンドシップ（エリトラの額縁の位置） | BDS の `/locate` と、実機のワールドデータ（エリトラの額縁 6 か所）で一致を確認 |
| エンドゲートウェイ（中央の島。何回目の討伐で出るかも） | 実機のワールドデータのゲートウェイと出た順番で一致を確認 |
| エンドゲートウェイ（外側の島） | BDS と実機のワールドデータ 21 か所中 20 か所と一致（隣のチャンクのコーラスの影響でまれに外れる） |
| ジオード / 化石 | 推定（場所は実機のワールドデータとほぼ全部一致。ただし 2 割ほどは洞窟などで削られて無い） |
| ネザーの化石 | 参考（ソウルサンドの谷の候補のうち実際にできるのは 4 割ほど） |
| ダンジョン | 出せない（1 チャンク 14 回の試行のどれが成功するかが洞窟の形で決まる） |
| 海底神殿 / 森の洋館 / ピリジャーの前哨基地 / 難破船 / 海底遺跡 / 埋もれた宝 / 荒廃したポータル / 古代都市 / 旅路の遺跡 / 放棄されたキャンプ / 廃坑 | 推定（場所の計算式は複数の解析ツールで一致。生成されるバイオームの条件に推定が入る） |
| 要塞 | 村の下に必ずできる 3 つだけ |
| 砂漠の井戸 | 参考 |

### 要塞について

統合版の要塞は 2 種類あります。

1. 原点の近く（453 ブロック以上離れた所）で、**村の下に必ずできる 3 つ**。ワールドのシードで決まる角度と距離（40〜55 チャンク）から探し始め、その周り 16×16 チャンクに村があればそこに置きます。見つからなければ 45° 回して 4 チャンク遠くを探します。このツールに出るのはこの 3 つです。
2. ワールドのあちこちにランダムにできる要塞。統合版での計算式が公開・検証されていないため出せません。エンダーアイで探してください。

### 座標について

- 座標は構造物の中心チャンクの中央（試練の間・放棄されたキャンプは開始部分の中心）です。大きな構造物では入口まで数十ブロック離れていることがあります。
- 高さ（Y）は出ません。地下の構造物は目安の高さをブラウザ版の詳細に書いています。
- ネザーの構造物はネザーの座標です（中心も地上の 1/8 にします）。ブラウザ版では同じ場所の地上の座標も添えています。
- 統合版の最初のスポーン地点は原点（0, 0）付近です。中心は変えられます。

## しくみ

- **地形とバイオーム**: 1.18 以降は同じシード値なら Java 版と統合版で地形・バイオームが同じなので、[cubiomes](https://github.com/Cubitect/cubiomes)（新しいバージョンに対応した [xpple のフォーク](https://github.com/xpple/cubiomes)、MIT ライセンス）を `vendor/cubiomes` に同梱して使っています。
- **構造物の場所**: 統合版は領域ごとにメルセンヌ・ツイスタをシードの下位 32 ビットから作り直して位置を決めます（`src/bedrock.c`）。旅路の遺跡・試練の間・放棄されたキャンプは統合版でも Java 版と同じ配置です。
- 定数と規則は、実機の座標と照合されているオープンソースの統合版ツール [SeedFinder](https://github.com/zebedelu/SeedFinder)・[MCBE-seedcracker](https://github.com/Alist2930/MCBE-seedcracker)・[mc-mapper](https://github.com/BrendonKing32/mc-mapper) に揃えています。
- 村と前哨基地は、統合版だけの「雪のタイガ」「ヒマワリ平原」でもできるようにしています。
- **ネザー**: 要塞と砦の遺跡は 30 チャンク四方の領域ごとに 1 つの候補を取り合い、6 回に 2 回が要塞になります。砦の遺跡は玄武岩の三角州にはできず、その領域は空になります（Java 版のように要塞にはなりません）。ネザーのバイオームは統合版だけの計算（メルセンヌ・ツイスタで作ったパーリンノイズを高さによらず 2 次元で取る）で、Java 版とは違うので自前で計算しています。
- **スライムチャンク**: チャンク座標 `(cx * 0x1f1f1f1f) ^ cz` で作ったメルセンヌ・ツイスタの最初の出力が 10 で割り切れるチャンクです。
- **エンド**（`src/end.c`）: 統合版のエンドは Java 版 1.12 のエンドの生成を float とメルセンヌ・ツイスタで計算したもので、Java 版 1.13 以降（cubiomes）とは島の形も場所も違います。統合版の専用サーバーを移植した [acacia-rs/sapling](https://github.com/acacia-rs/sapling) と Java 版 1.12 の EndCityPieces をもとに、島の地形・エンドシティの部品・コーラスフラワーの育ち方まで計算しています。丸めまで合わせるため `-ffp-contract=off` でコンパイルします。
- **ジオード・化石・ネザーの化石・砂漠の井戸**: 装飾の規則ごとの乱数（規則の名前を FNV-1 にした値で種を変える）で決まります。ネザーの化石は 1.21.90 で規則が変わったので、ブラウザ版のバージョン欄で分けています。

## ビルド

```sh
./build.sh          # コマンドライン版 → build/mcbe-structures
./build.sh test     # 既知の座標との照合テスト
./build.sh wasm     # ブラウザ用 web/engine.wasm（zig が必要: pip install ziglang）
./build.sh page     # web/ を 1 ファイルにまとめた dist/index.html
```

コマンドライン版:

```sh
./build/mcbe-structures 6666                      # 原点 ±10000 の全部
./build/mcbe-structures 6666 --range 3000 --kinds 0,17   # 村と要塞だけ
./build/mcbe-structures "文字のシード" --center 500 -200
```

`--kinds` の番号: 0 村, 1 砂漠のピラミッド, 2 ジャングルの寺院, 3 ウィッチの小屋, 4 イグルー, 5 海底神殿, 6 森の洋館, 7 ピリジャーの前哨基地, 8 難破船, 9 海底遺跡, 10 埋もれた宝, 11 荒廃したポータル, 12 古代都市, 13 旅路の遺跡, 14 試練の間, 15 放棄されたキャンプ, 16 廃坑, 17 要塞, 18 砂漠の井戸, 19 ネザー要塞, 20 砦の遺跡, 21 スライムチャンク, 22 ジオード, 23 化石, 24 ネザーの化石, 25 エンドシティ, 26 エンドシップ, 27 エンドゲートウェイ, 28 エンドゲートウェイ（外側の島）。ネザーの構造物はネザーの座標で、中心も 1/8 になります。

`--mc` には対応する Java 版のバージョンを書きます（既定は最新の 26.3 = 統合版 26.50 以降）。統合版との対応はブラウザ版のバージョン欄と同じで、たとえば統合版 1.21.50 なら `--mc 1.21.4`、1.21.0〜1.21.40 なら `--mc 1.21.3` です。

## テスト

`tests/ground_truth.c` で次の座標と照合しています（`./build.sh test`）。

- シード 6666: 実機で確かめられた村 8 か所と、川に落ちて村ができない 3 か所
- シード 4294972605: Chunkbase の村 5 か所・神殿 4 か所・試練の間 4 か所
- シード 20261003: 統合版のサーバー（BDS 1.26.52）の `/locate structure fortress` が返したネザー要塞 9 か所（±100 万ブロックまで）
- 実機のワールドデータ: ネザー要塞の開始ピース 4 か所、砦の遺跡 8 か所とその形、玄武岩の三角州で空になった領域 2 か所、ネザーのバイオーム 9 点
- スライムチャンク 7 チャンク（[rbedrock](https://github.com/reedacartwright/rbedrock)・[slime-finder-pe](https://github.com/depressed-pho/slime-finder-pe) のテストより）
- ジオード 4 か所・化石 6 か所・ネザーの化石 4 か所（実機のワールドデータ。化石はマングローブの沼地の深層岩の化石を含む）
- シード 20261003: BDS の `/locate structure end_city` が返したエンドシティ 6 か所
- 実機のワールドデータ: エンドシップのエリトラの額縁 6 か所、ドラゴンを倒したあとの中央のゲートウェイ（1 回目 6 ワールド、5 回倒したワールドの順番）、外側の島のゲートウェイ 6 か所
