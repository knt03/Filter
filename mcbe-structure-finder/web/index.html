統合版 構造物座標帳

Minecraft 統合版のシード値から、スポーン地点（原点）の周り ±10000 にある村・要塞・ピラミッド・海底神殿などの座標を全部書き出します。非公式ツール。

種類（タップで表示を切り替え）

上が北（Z−）、右が東（X＋）。＋印が原点。地図をタップすると近くの構造物を表示します。

スライムチャンクは、地図を拡大すると塗って表示します。

座標一覧

  • シード値を入れて「計算する」を押してください。

座標の確かさ

  • 村・砂漠のピラミッド・ジャングルの寺院・ウィッチの小屋・イグルー・試練の間は、実機や Chunkbase で確かめられた座標と一致することを確認済みです。
  • ネザー要塞・砦の遺跡は、統合版のサーバーの /locate の答え 85 件と、実際のワールドデータ 5 つに残っていた要塞・砦の遺跡と一致することを確認済みです。座標はネザーの座標で、一覧には同じ場所の地上の座標（8 倍）も添えています。砦の遺跡の「形」（橋・宝物庫・ホグリン小屋・住居）も出ます。
  • スライムチャンクはどのワールドでも同じ場所です（シード値は関係ありません）。Y 39 以下なら明るさに関係なくスライムが湧きます（キノコ島とディープダークを除く）。地図を十分に拡大するとチャンクが塗られます。
  • 推定 の付いた種類は、場所の計算式は複数の解析ツールで一致していますが、「そのバイオームで本当にできるか」の条件に推定が入ります。まれに、行ってみたら無い・一覧に無いのにある、ということがあります。
  • 要塞は統合版では 2 種類あります。原点の近くで村の下に必ずできる 3 つはここに出ます。それ以外にもランダムにできますが、その計算式は公開されていないため出せません。エンダーアイで探してください。
  • 座標は構造物の中心チャンクの中央です。大きな構造物では入口まで数十ブロック離れていることがあります。高さ（Y）は出せないので、地下のものは目安の高さを地図の詳細に書いています。
  • 統合版の最初のスポーン地点は原点（0, 0）付近です。別の場所を中心にしたいときは「中心 X / Z」を変えてください。
  • 地上の地形とバイオームは 1.18 以降 Java 版と同じ計算なので、cubiomes（Java 版の地形計算ライブラリ）を使っています。ネザーのバイオームは統合版だけの計算式で、実機のワールドデータと一致することを確認しています。
